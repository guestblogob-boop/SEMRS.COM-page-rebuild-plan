Free blocks for any block theme or classic theme: SEMRS, Astra, GeneratePress, Kadence, Twenty Twenty-Five.

== Description ==

Every block is rendered on the server, so pages stay fast and search engines see the real content. CSS and JavaScript load only on pages that use a block.

= Free blocks =
* Icon: 48 original SVG icons, colour, size, circle or rounded background, optional link.
* Icon List: checklists and feature lists in 1 to 4 columns.
* Fancy Heading: typing (rotating words), gradient, marker highlight, curved underline and outline styles.
* Posts: card grid, list, masonry, overlay and compact layouts, with category, post type, order, offset and display options.
* Countdown Timer: boxes or inline, with a message when it ends.
* Pricing Card: features with included and not-included items, highlight, badge.
* Service / Feature Card: icon or image, three styles.
* Contact Form: phone with a country picker (flags and dialling codes), WhatsApp opt-in, company, website, service and budget choices, project requirements, consent. Leads are saved under Leads and emailed to you. Built-in spam protection (honeypot, time check, rate limit, link limit). Sends the GA4 generate_lead event.
* Free Media Sites: a directory of free photo, video, illustration, icon, animation and 3D sites, with a licence note for each.

= Product block =
* Product page, buy box or shop-grid card layouts.
* Colour swatches, size buttons, dropdowns and plan cards from a simple text format ("Color: Navy #1e3a66, Sand #d8c7a3", "Size: S, M, L +2", "(sold out)").
* Personalisation fields (names, dates) with character limits, quantity with bulk discounts, bundle add-ons, live price, savings and total.
* The button opens your own checkout (WooCommerce, Shopify, Stripe Payment Links…) with the choices as URL parameters; chosen options are kept in the page address for sharing.
* Optional Product schema with price and availability only. Store patterns: shop grid, product page, bundle offer, bulk pricing and store promises.
* Ready-made shops (digital downloads, crochet patterns) are in the separate SEMRS Shops plugin.

= Layout blocks =
* Container: section, row or grid (1–6 columns) with background colour, gradient or image and overlay, padding, minimum height, width and HTML element. Holds any blocks.
* Tabs: any blocks in each tab; underline, pills, boxed or vertical; keyboard accessible; all content visible to search engines.
* Accordion / FAQ: native open/close, optional one-at-a-time, FAQ schema with SEMRS Core SEO.
* Gallery & Lightbox: grid or masonry, accessible lightbox with keyboard and swipe.
* Testimonial: quote, name, role, photo, stars and a link to the original review (no self-serving review schema).
* Table of Contents: automatic jump links to the page headings.
* Website Showcase: theme, template or portfolio cards with desktop and mobile previews and a Desktop / Mobile switch, like the WordPress.org theme directory.

= Templates & starter sites =
SEMRS → Templates: 16 free starter sites (Agency, SEO Services, Digital Marketing, Content Marketing, Social Media, Guest Blogging, Local Business, Cleaning, Handyman, Repair Shop, Gardening, Pet Care, Dentist, Blog, Top 10 Lists, Travel Blog), imported in one click with your business name, phone, email and city filled in. Sets the home page, blog page and menu. Every page is also an editor pattern, plus 12 single sections and 6 header / 3 footer presets for the SEMRS theme. Everything is bundled: nothing is downloaded. Original GPL illustrations included.

= Visibility =
Hide any block on phones, tablets or desktops from the block sidebar. CSS-based, so it works with page caching.

= SEMRS Pro adds =
Slider / carousel (images or posts), animated counter, 3D model viewer with AR, scroll animations and display conditions (login, role, schedule, page type) on every block, and popups.

= Manage blocks =
SEMRS → Blocks (or SEMRS Blocks in the menu when SEMRS Core is not installed) lists every block with a short description, search and Free / Pro / category filters. Switch off blocks you do not use; a switched-off block is not loaded at all.

Pro blocks appear with a PRO label until SEMRS Pro is installed. They print nothing on your site, and you can hide them from the inserter on the same screen.
