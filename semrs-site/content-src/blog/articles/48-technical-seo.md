Technical SEO makes sure search engines can find, read and index your pages, and that visitors get a fast, secure site. Great content cannot rank if Google cannot reach it. This checklist covers the basics every small business site needs, how to check each one and what to fix first.

## Key takeaways

- Google's minimum requirements: Googlebot is not blocked, the page returns a 200 status and it has indexable content.
- Most small sites need only a handful of fixes: indexing, HTTPS, speed, mobile layout, redirects and sitemaps.
- Google Search Console shows most technical problems for free.

[glance: Technical SEO at a glance | Crawlable | Indexable | Fast and secure | Clean structure]

## How search engines see your site

@img chart

Search works in layers. Google first **crawls** a page, then **renders** it, then decides whether to **index** it, and only then can it **rank** it. A problem in a lower layer blocks everything above it.

Google's technical requirements page lists three minimum requirements for a page to be eligible for indexing:

1. Googlebot is not blocked.
2. The page works, returning an HTTP 200 (success) status code.
3. The page has indexable content.

Meeting them does not guarantee indexing, but missing any one of them stops it.

## The technical SEO checklist

| Check | How to check it | What good looks like |
|---|---|---|
| Indexing | Search Console page indexing report | Important pages indexed |
| robots.txt | Visit yoursite.com/robots.txt | No important pages blocked |
| Noindex tags | Page source or SEO plugin | Only on thin pages such as thank-you pages |
| HTTPS | Browser padlock | Every page on HTTPS, old HTTP URLs redirect |
| Speed | PageSpeed Insights | Good Core Web Vitals on mobile |
| Mobile layout | Open the site on a phone | Readable text, tappable buttons |
| XML sitemap | Search Console sitemaps report | Submitted, no errors |
| Redirects | Click old links | One 301 hop to the right page |
| Broken links | Site crawl or link checker | None on important pages |
| Structured data | Rich results test | Valid Organization, LocalBusiness and Article data |

## Fix these first

1. **Pages that should rank but are not indexed.** Check robots.txt, noindex tags and canonical tags.
2. **Slow mobile pages.** Compress images and remove heavy scripts. Our free [image compressor](/tools/image-compressor/) helps.
3. **Redirect chains and broken links** after a redesign. Our guide to [website redesign](/website-redesign/) explains URL mapping.
4. **Missing or broken sitemap.** Most CMSs create one automatically.

## Do you need a sitemap?

Google's sitemap guide says a small site, about 500 pages or fewer, may not need one if it is well linked internally. A sitemap still helps new sites with few links, large sites and sites with lots of images or video. Submitting one costs nothing.

## WordPress settings to check

WordPress handles many basics, but check:

- **Settings, Reading:** "Discourage search engines" must be off on the live site.
- **Permalinks:** use readable addresses such as /service-name/.
- **One SEO plugin**, not two, to avoid duplicate tags.
- **Updates and backups** to keep the site secure.

## Frequently asked questions

? What is technical SEO?
Technical SEO is the work that lets search engines crawl, render and index your site, and gives visitors a fast, secure, mobile-friendly experience.

? How do I check my site for free?
Use Google Search Console for indexing and sitemaps, PageSpeed Insights for speed, and a phone for the mobile layout. Free tools such as the SEMRS [on-page SEO checker](/tools/on-page-seo-checker/) help with page-level checks.

? How often should I run an audit?
Check Search Console monthly and run a fuller audit after a redesign, a platform change or a sudden drop in traffic.

? Is it more important than content?
Both matter. Technical work makes pages eligible to rank; helpful content earns the ranking. Fix blocking issues first, then focus on content.
