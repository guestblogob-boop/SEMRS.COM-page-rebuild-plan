The templates library is part of the free SEMRS Blocks plugin. Everything is included in the plugin: nothing is downloaded from the internet and no account is needed.

Open SEMRS → Templates (or SEMRS Blocks → Templates if SEMRS Core is not installed). There are three tabs: Starter sites, Headers & footers and Pages & sections.

Starter sites

Each card has a Desktop / Mobile switch so you can see the design on both before importing.

How to import

  1. Click Import on a starter site.
  2. Enter your business or site name, phone, email (contact form messages go here), city and country code. These fill in the text automatically.
  3. Choose Create as drafts (recommended) or Publish now.
  4. Keep the boxes ticked to set the home page (and blog page), create the main menu, and apply the header layout and contact details (SEMRS theme).
  5. Click Import starter site. The result screen links to every new page.

Safe by design: existing pages, posts and settings are never deleted. If a page with the same address already exists (for example /contact/), it is skipped and listed in the report.

After importing

  • Replace example prices, opening hours and areas with your own.
  • Replace the illustrations with your own photos if you like: select the image → Replace.
  • Read every page before publishing; the text is a starting point written for your type of business.
  • Real customer reviews are never included: add your own genuine testimonials with the Testimonial block.

Headers & footers

Six header layouts (Classic, Top bar + classic, Centred logo, Two rows, Minimal, Transparent hero) and three footer layouts (Simple, Centred, Contact), each shown as a small diagram. Click Apply to use one, then fine-tune it in Customize → SEMRS Theme → Header builder / Footer builder. Needs the free SEMRS theme.

Pages & sections in the editor

Every page of every starter site you can use is also available as a pattern, plus 12 single sections:

  1. Edit a page and click + → Patterns.
  2. Choose SEMRS full pages (home, about, services, admissions, contact…) or SEMRS sections (hero, services, about, steps, pricing, FAQ, call to action, contact, opening hours, latest posts, page header).
  3. Click a design to insert it and edit the text.

Images and licences

All illustrations are original artwork made for SEMRS and are GPL-licensed, so you can use them on any site. They are copied into your Media Library on the first import.

Ready-made shops (SEMRS Shops plugin)

Install the free SEMRS Shops plugin (it needs SEMRS Blocks) to add two complete shops to SEMRS → Templates, each in four storefront styles:

Every product page uses the Product block: colour swatches, sizes, formats and licences, personalisation fields, bundle add-ons and bulk prices, with a live total. Add your checkout link (WooCommerce, Shopify, Stripe Payment Links, Lemon Squeezy, Gumroad) to each product; until then the button says "Not available yet".

Tools → Shop exports downloads each catalogue as a Shopify product CSV and an Etsy listing sheet. Example prices follow 2026 marketplace medians; review them, and replace the delivery, refund and licence placeholders with your real policies before publishing.
